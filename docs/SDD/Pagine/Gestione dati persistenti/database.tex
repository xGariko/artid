\section{Gestione dei Dati Persistenti}

Il livello di memorizzazione è realizzato su un \textbf{DBMS relazionale} interrogato tramite \textbf{interfaccia SQL}, che assicura il rispetto delle proprietà ACID. La permanenza dei file è affidata a un object storage esterno.
