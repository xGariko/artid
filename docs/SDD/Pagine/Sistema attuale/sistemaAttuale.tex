% ==========================================
\section{Architettura software attuale}
% ==========================================

Al momento non esiste alcuna architettura software stabilita che ricopre il ruolo che ArtID si propone di ricoprire.

Tutte le funzionalità offerte dal sistema sono infatti al momento gestite manualmente e senza supporto di software dedicati, appoggiandosi al più a repository esterni o file storage locali per la memorizzazione dei contenuti multimediali.
